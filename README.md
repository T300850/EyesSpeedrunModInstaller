# EN
Copy all files from the Installer folder into the game directory (the folder that contains Eyes.exe and Eyes_Data).
Run TL12Installer.exe and follow the prompts — the mod will be installed automatically.

# RU
Скопируйте все файлы из папки Installer в папку с игрой (туда, где находится Eyes.exe и папка Eyes_Data).
Запустите TL12Installer.exe и следуйте подсказкам — мод установится автоматически.
